BookMyShow UI Clone

A frontend UI clone inspired by the BookMyShow website, created using HTML and CSS. This project focuses on recreating the visual layout, movie/event cards, banners, hover effects, and footer without JavaScript.

Features

Promotional banner section

Recommended Movies section

Live Events section

Premieres section

Laughter Therapy / comedy events section

Movie and event cards

Rating icons using Remix Icon

Play button icons

Hover effects

BookMyShow-inspired dark footer

Customer care, booking confirmation, and newsletter section

Movie, genre, language, city, country, and help links

Social media icons

Footer classes use the bs- prefix to avoid CSS conflicts

Technologies Used

HTML5

CSS3

Remix Icon

How to Run

Download or clone the project.

Open the project folder.

Make sure index.html and style.css are connected.

Open index.html in a browser.

No backend or installation is required.

HTML and CSS Only

This project is designed primarily with HTML and CSS, without JavaScript for the main UI. CSS hover effects and layout techniques are used to recreate the visual experience.
