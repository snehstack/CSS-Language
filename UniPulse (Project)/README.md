# 🎓 UniPulse — University Website

A modern and responsive **university website landing page** built with **HTML5 and CSS3**. UniPulse is designed to present a clean academic interface with an attractive navigation system, hero section, feature cards, upcoming events, university information, milestones, and a professional footer.
